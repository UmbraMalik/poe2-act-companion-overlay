# Локальная подготовка кампании PoE 2 1.0

Этот патч **не добавляет выдуманные игровые маршруты** и не изменяет репозиторий GitHub.

- В настройках, в разделе языка, можно выбрать профиль `0.5` (по умолчанию) или `1.0` (заготовка).
- В режиме 0.5 остаются акты 1–4, старые Интерлюдии (в истории таймера это акт 5) и эндгейм/T15 (акт 6).
- В режиме 1.0 доступны акты 1–6; акты 5–6 пока без подтверждённых локаций, карты показывают заглушку. Для эндгейма зарезервирован индекс 7.
- Профиль забега сохраняется в истории; старые записи автоматически считаются 0.5. Сравнение результатов и рекорды разделяются по профилям.
- Профиль нельзя переключать во время активного забега. Завершите или сбросьте таймер.
- Встроенные алиасы для старых Интерлюдий не применяются к 1.0. В `LatestClient.txt` будущие коды `G6_*` определяются как акт 6; пока непроверенные имена зон не подставляются.

После релиза останется заполнить `guide.json`, бонусы, локализацию и реальные area-ID на основании игровых логов и проверенных источников. Не используйте тестовую заготовку как готовый гайд 1.0.

Проверка после применения: `npm ci`, `npm run test:regression`, `npm run build`.
